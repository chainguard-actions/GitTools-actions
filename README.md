# GitTools/actions

GitHub Action for creating and exporting releases for software applications hosted on GitHub. Adds assets to a release

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/GitTools/actions](https://github.com/GitTools/actions).

## Privacy

This Action contacts Chainguard's licensing server to verify authorization. Connection metadata (IP address, GitHub repository identifier, timestamp, and any metadata encoded in the auth token) is transmitted to Chainguard, Inc. even if authorization is denied in accordance with our [Privacy Notice](https://www.chainguard.dev/legal/privacy-notice)
